# Functional Requirements

## 1. User Management

### FR-001: Create Employee Account

**Description:**  
The system shall allow an Admin to create employee accounts by providing the required employee information.

**Priority:** High

### FR-002: Employee Login

**Description:**  
The system shall allow employees to log in using their registered email address and password.

**Priority:** High

### FR-003: Employee Logout

**Description:**  
The system shall allow logged-in employees to log out of their accounts.

**Priority:** High

### FR-004: Update Employee Profile

**Description:**  
The system shall allow employees to update their personal profile information.

**Priority:** Medium

### FR-005: Activate / Deactivate Employee Account

**Description:**  
The system shall allow an Admin to activate or deactivate employee accounts.

**Priority:** High

### FR-006: Change Password

**Description:**  
The system shall allow employees to change their account passwords.

**Priority:** High

### FR-007: Reset Password

**Description:**  
The system shall allow employees to reset their passwords if they forget them.

**Priority:** High


### FR-008: Create Team

**Description:**  
The system shall allow an Admin to create a new team by providing its name and description.

**Priority:** High

### FR-009: Update Team Information

**Description:**  
The system shall allow an Admin to update a team's name and description.

**Priority:** Medium

### FR-010: Archive Team

**Description:**  
The system shall allow an Admin to archive a team that is no longer active.

**Priority:** Medium

### FR-011: Add Team Members

**Description:**  
The system shall allow an Admin to add employees to a team.

**Priority:** High

### FR-012: Remove Team Members

**Description:**  
The system shall allow an Admin to remove employees from a team.

**Priority:** High

### FR-013: Assign Team Leader

**Description:**  
The system shall allow an Admin to assign an employee as the Team Leader of a team.

**Priority:** High

### FR-014: View Team Information

**Description:**  
The system shall allow employees to view team details, including team members and the assigned Team Leader.

**Priority:** Medium

## 3. Project Management

### FR-015: Create Project

**Description:**  
The system shall allow an Admin or an authorized Project Manager to create a new project by providing its name, description, start date, and expected deadline.

**Priority:** High

### FR-016: Update Project Information

**Description:**  
The system shall allow an authorized Project Manager to update project information.

**Priority:** High

### FR-017: Archive Project

**Description:**  
The system shall allow an authorized Project Manager to archive a completed or inactive project.

**Priority:** Medium

### FR-018: Assign Teams to Project

**Description:**  
The system shall allow an authorized Project Manager to assign one or more teams to a project.

**Priority:** High

### FR-019: Assign Employees to Project

**Description:**  
The system shall allow an authorized Project Manager to assign employees to a project.

**Priority:** High

### FR-020: Remove Employees from Project

**Description:**  
The system shall allow an authorized Project Manager to remove employees from a project.

**Priority:** Medium

### FR-021: View Project Information

**Description:**  
The system shall allow project members to view project details, including its description, assigned teams, members, start date, deadline, and status.

**Priority:** High

### FR-022: Update Project Status

**Description:**  
The system shall allow an authorized Project Manager to update the project's status.

**Priority:** High

### FR-023: View Project Progress

**Description:**  
The system shall allow project members to view the overall progress of their projects.

**Priority:** Medium

## 4. Task Management

### FR-024: Create Task

**Description:**  
The system shall allow an authorized Project Manager or Team Leader to create tasks within a project by providing a title and description.

**Priority:** High

### FR-025: Assign Task

**Description:**  
The system shall allow an authorized Project Manager or Team Leader to assign a task to an employee who is a member of the project.

**Priority:** High

### FR-026: Update Task Information

**Description:**  
The system shall allow the Project Manager or Team Leader to update task details, including its title and description.

**Priority:** Medium

### FR-027: Set Task Priority

**Description:**  
The system shall allow the Project Manager or Team Leader to set or update a task's priority.

**Priority:** High

### FR-028: Set Task Deadline

**Description:**  
The system shall allow the Project Manager or Team Leader to set or update a task's deadline.

**Priority:** High

### FR-029: Update Task Status

**Description:**  
The system shall allow the employee assigned to a task to update its status.

**Priority:** High

### FR-030: View Task Details

**Description:**  
The system shall allow project members to view task details, including its description, assigned employee, priority, deadline, and status.

**Priority:** High

### FR-031: Search and Filter Tasks

**Description:**  
The system shall allow project members to search and filter tasks based on criteria such as status, priority, and assigned employee.

**Priority:** Medium

### FR-032: View Assigned Tasks

**Description:**  
The system shall allow employees to view the tasks assigned to them across their projects.

**Priority:** High

### FR-033: Report Bug

**Description:**  
The system shall allow project members to report bugs by providing a title, description, and severity level.

**Priority:** High

### FR-034: Assign Bug

**Description:**  
The system shall allow authorized Project Managers or Team Leaders to assign reported bugs to project members.

**Priority:** High

### FR-035: Set Bug Severity

**Description:**  
The system shall allow authorized Project Managers or Team Leaders to set or update the severity level of a bug.

**Priority:** High

### FR-036: Update Bug Status

**Description:**  
The system shall allow the employee assigned to a bug to update its status.

**Priority:** High

### FR-037: View Bug Details

**Description:**  
The system shall allow project members to view bug details, including its description, severity level, assigned employee, and status.

**Priority:** High

### FR-038: Filter Bugs

**Description:**  
The system shall allow project members to filter bugs by status, severity level, and assigned employee.

**Priority:** Medium
